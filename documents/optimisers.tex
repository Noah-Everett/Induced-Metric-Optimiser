\section{Introduction}\label{sec:intro}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Thomas~\cite{harvey2025} introduced a class of optimisers that precondition gradients
using the Riemannian metric naturally induced when the loss landscape is embedded in
higher-dimensional space.
The key idea is to embed the $N$-dimensional parameter space into $\mathbb{R}^{N+1}$
via the loss function, equip the ambient space with a metric~$h$, and pull~$h$ back to
obtain a geometry-aware preconditioner.
The resulting update automatically damps the effective learning rate in high-curvature
regions---acting as a smooth form of gradient clipping---while adding only $O(N)$ overhead.

This document extends that framework in three directions
(summarised in Table~\ref{tab:variants}):

\begin{enumerate}[label=(\roman*)]
    \item \textbf{Learnable scalar metric} (Section~\ref{sec:scalar}):
    the inverse base metric $\gamma^{-1}$ is parameterised by a single learnable scalar $s$,
    allowing the overall metric scale to adapt during training.

    \item \textbf{Learnable diagonal metric} (Section~\ref{sec:diag}):
    each parameter receives its own learnable scale $s_i$,
    enabling per-parameter metric adaptation with a principled
    gauge-fixing (mean-centering) to remove the degeneracy with the global
    scaling hyperparameter~$\xi$.

    \item \textbf{Off-diagonal ambient metric} (Section~\ref{sec:offdiag}):
    the ambient metric $h$ in~\cite{harvey2025} has no coupling between
    the parameter dimensions and the loss dimension (the off-diagonal blocks are zero).
    We relax this by introducing coupling vectors $\vecb{a}$ and $\vecb{b}$,
    which add a second component to the update direction
    and enable geometry-induced momentum, weight decay, and other behaviours.
\end{enumerate}

\section{Setup and Notation}\label{sec:setup}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
Given a model with $N$ parameters $\theta(t)=\{\theta^i(t)\}_{i=1}^N$ and a loss function
$\loss:\mathbb{R}^N\to\mathbb{R}$,
our goal is to find the optimal parameter update $\delta \theta$ at each time step $t$.
That is, in preconditioned gradient flow we have
\begin{equation}\label{eq:grad-flow}
    \frac{d \theta^i}{dt} = - g^{ij} \frac{\partial \loss}{\partial \theta^j}
    \implies
    \delta \theta^i \approx - \eta g^{ij} \frac{\partial \loss}{\partial \theta^j}
\end{equation}
where $\eta\in\mathbb{R}_{>0}$ is the learning rate and $g^{ij}$ is the inverse of the induced metric on the parameter space.

Across all variants in this document the induced metric is obtained by the same geometric construction:
we embed parameter space into an ambient space via $$
    \phi:\mathbb{R}^N\to\mathbb{R}^{N+1}, \qquad
    \phi(\theta^1,\ldots,\theta^N) = (\theta^1,\ldots,\theta^N,f(\theta)),
$$ where $f:\mathbb{R}^N\to\mathbb{R}$ is a scalar function of the parameters (taken to be the loss $\loss$, or a function thereof), and then pull back an ambient bilinear form $h\in\mathbb{R}^{(N+1)\times(N+1)}$ to the parameter space.
The variants differ in the choice of $h$ (and, for the log-loss variant, the embedding function $f$; see below).

We use the shorthand $l_i\coloneqq \partial \loss/\partial\theta^i$ for the raw gradient.
When a base metric $\gamma_{ij}$ is present, we write $l^i \coloneqq \gamma^{ij} l_j$ for the
metric-raised gradient (i.e.\ the inverse metric applied to $\vecb{l}$).
When $\gamma = \Id_N$ (the identity), raising an index has no effect, so $l^i = l_i$ and the two notations coincide.
The same index-raising convention applies to any covector:
$a^i \coloneqq \gamma^{ij}a_j$, $m^i \coloneqq \gamma^{ij}m_j$, etc.

\section{Fixed Diagonal Metric}\label{sec:fixed}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
This section reproduces the core method of \cite{harvey2025}:
a fixed base metric $\gamma$ defines the ambient space geometry,
and the induced metric on parameter space provides a preconditioner
for gradient descent.
The geometric derivation, practical algorithms,
and all notation established here
carry forward to the extensions in
Sections~\ref{sec:scalar}--\ref{sec:offdiag}.

\subsection{Geometric Derivation}

The following derivation is due to Thomas~\cite{harvey2025};
we reproduce it here to establish notation for the extensions that follow.

The ambient metric in \cite{harvey2025} is $$
    h = \begin{pmatrix} \gamma & \vecb{0} \\ \vecb{0}^\top & 1 \end{pmatrix}\in\mathbb{R}^{(N+1)\times(N+1)}
$$ where $\gamma\in\mathbb{R}^{N\times N}$ is symmetric positive-definite (taken to be diagonal or scalar in all our experiments).
The induced metric $g$ on the parameter space is given by
\begin{equation}\label{eq:induced-metric}
    g_{ij}
    = h_{\alpha\beta} \frac{\partial \phi^\alpha}{\partial \theta^i} \frac{\partial \phi^\beta}{\partial \theta^j}
    = \gamma_{ij} + \frac{\partial \loss}{\partial \theta^i} \frac{\partial \loss}{\partial \theta^j}.
\end{equation}
Then, to calculate the parameter updates $\delta \theta^i$ we need $g^{ij}$, the inverse of $g_{ij}$.
We can compute this inverse using the Sherman-Morrison-Woodbury formula:
\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable, title=\textbf{Sherman-Morrison-Woodbury Formula}, coltitle=black]
    Let $A\in\mathbb{R}^{n\times n}$ be an invertible matrix, and let $U,V\in\mathbb{R}^{n\times k}$ be matrices.
    Then, if $C = A + U V^\top$ is invertible, we have $$C^{-1} = A^{-1} - A^{-1} U (I_k + V^\top A^{-1} U)^{-1} V^\top A^{-1}.$$
\end{tcolorbox}
\noindent This gives us
\begin{equation}\label{eq:inverse-metric}
    g^{ij}
    = \gamma^{ij} - \frac{\gamma^{ik}\gamma^{jl} \frac{\partial \loss}{\partial \theta^k} \frac{\partial \loss}{\partial \theta^l}}{1 + \gamma^{mn} \frac{\partial \loss}{\partial \theta^m} \frac{\partial \loss}{\partial \theta^n}}
    = \gamma^{ij} - \frac{l^i l^j}{1+l_k l^k}
\end{equation} where $$
    l_i \coloneqq \frac{\partial\loss}{\partial \theta^i} \implies l^i = \gamma^{ij} l_j.
$$ Thus, the parameter updates are given by
\begin{align}\label{eq:fixed-theory}
    \delta \theta^i =& -\eta \left( \gamma^{ij} - \frac{l^i l^j}{1+l_k l^k} \right) l_j \nonumber\\
    =& -\eta l^i \left( 1 - \frac{l_j l^j}{1+l_k l^k} \right) \nonumber\\
    =& -\frac{\eta\, l^i}{1+l_k l^k}.
\end{align}

So to summarize, (i) we start with an ambient metric $h$ which induces a metric $g$ on the parameter space,
(ii) we compute the inverse $g^{ij}$, and
(iii) we use $g^{ij}$ to compute the parameter updates $\delta \theta^i$.

For a single component with $\gamma=\Id_N$,
the update $\delta\theta^i/\eta = -l_i/(1 + \sum_k l_k^2)$
depends on both $l_i$ and the other gradients $\{l_k\}_{k\neq i}$.
Figure~\ref{fig:step-fixed} plots this as a function of $l_i$
for several fixed values of $\sum_{k\neq i} l_k^2$.

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.75\textwidth]{../images/step_profile_fixed.png}
    \caption{Step-size profile for the fixed diagonal metric ($\gamma=\Id$, $\xi=1$):
    $\delta\theta^i/\eta = -l_i/(1 + \sum_k l_k^2)$ plotted as a function of $l_i$
    for several fixed values of $\sum_{k\neq i}l_k^2$.
    For small gradients the update is approximately linear (like SGD);
    for large gradients it saturates, providing smooth gradient clipping.
    More background curvature from the other parameters produces stronger damping.
    Compare Figure~2 of~\cite{harvey2025}.}
    \label{fig:step-fixed}
\end{figure}

\subsection{Practical Algorithm}\label{sec:practical}

The theoretical update \eqref{eq:fixed-theory} is clean but not directly usable in stochastic training.
Thomas~\cite{harvey2025} bridges this gap with four modifications,
each of which is standard in the optimisation literature but takes on
a specific role in the induced-metric framework.

\paragraph{Metric strength $\xi$.}
The theoretical derivation implicitly sets $\xi=1$.
Geometrically, $\xi$ enters through the embedding itself:
one replaces $\phi(\theta) = (\theta, f(\theta))$ with $\phi(\theta) = (\theta, \sqrt{\xi}\,f(\theta))$,
which scales the loss dimension of the ambient space and yields the induced metric
$g_{ij} = \gamma_{ij} + \xi\,l_il_j$.
The parameter $\xi>0$ therefore controls how strongly the loss-surface curvature
influences the preconditioner:
$\xi\to 0$ recovers the base metric $\gamma^{-1}$, while large $\xi$
makes the geometric clipping dominant.

\paragraph{Momentum.}
An exponential moving average (EMA) of the raw gradients,
\begin{equation}\label{eq:momentum}
    \vecb{m}_t = \beta_m\,\vecb{m}_{t-1} + (1-\beta_m)\,\vecb{l}_t,
    \qquad \vecb{m}_0 = \vecb{0},
\end{equation}
replaces the instantaneous gradient with a smoothed direction.
Here $\beta_m\in[0,1)$ is the momentum decay:
$\beta_m=0$ recovers the raw gradient, while $\beta_m$ close to $1$
gives a long look-back (roughly $1/(1-\beta_m)$ steps).
The bias-corrected, metric-raised momentum
$\hat{\vecb{m}}_t = \gamma^{-1}\vecb{m}_t/(1-\beta_m^t)$
is then used as the step direction.
Momentum is not required by the geometric framework---the induced metric
works without it---but it provides the standard acceleration benefits
(variance reduction, faster traversal of flat regions)
and is included to match common practice.

\paragraph{Denominator EMA.}
The scalar $v_t = \xi\,\vecb{l}_t^\top\gamma^{-1}\vecb{l}_t$
is the metric-weighted squared gradient norm.
Thomas~\cite{harvey2025} calls it the \emph{trace statistic} because it equals
$\xi\cdot\operatorname{tr}(\gamma^{-1}\vecb{l}\,\vecb{l}^\top)$,
the trace of the rank-1 correction to the induced metric.
In stochastic training each minibatch (a random subset of the data) yields a different $v_t$.
To stabilise the damping factor, $v_t$ is smoothed with a \emph{second} EMA,
independent of the momentum EMA above
(momentum smooths the gradient \emph{direction}; this one smooths the scalar \emph{damping}):
\begin{equation}\label{eq:denom-ema}
    \bar{v}_t = \beta\,\bar{v}_{t-1} + (1-\beta)\,v_t,
    \qquad \bar{v}_0 = 0,
\end{equation}
bias-corrected to $\hat{v}_t = \bar{v}_t/(1-\beta^t)$.
The parameter $\beta\in[0,1)$ plays the same role as $\beta_m$:
it sets the look-back window, roughly $1/(1-\beta)$ steps.
The damping factor is then $r_t = 1/(1+|\hat{v}_t|)$.

\paragraph{Decoupled weight decay.}
Following~\cite{harvey2025}, weight decay is applied directly to the parameters
($+\lambda\,\theta_{t-1}$ with $\lambda\le 0$ for decay)
rather than through the loss gradient.
This decoupled form is the natural choice
from the geometric perspective due to general covariance~\cite{harvey2025}.
Like momentum, weight decay is not required by the induced-metric framework
but is included because it is standard practice and has a natural geometric justification.

\medskip\noindent
These modifications are collected in Algorithm~\ref{alg:fixed}
(adapted from Algorithm~1 of~\cite{harvey2025}).
The log-loss variant is Algorithm~\ref{alg:fixed-log}
(adapted from Algorithm~2 of~\cite{harvey2025}).

\begin{algorithm}[H]
\caption{Fixed diagonal metric (plain embedding, $f=\loss$)}
\label{alg:fixed}
\begin{algorithmic}[1]
\REQUIRE learning rate $\eta$, momentum decay $\beta_m$, metric strength $\xi$, denominator EMA decay $\beta$, weight decay $\lambda$, inverse base metric $\gamma^{-1}$
\STATE Initialise $t \leftarrow 0$, $\vecb{m}_0 \leftarrow \vecb{0}$, $\bar{v}_0 \leftarrow 0$
\WHILE{$\theta_t$ not converged}
\STATE $t \leftarrow t + 1$
\STATE $\vecb{l}_t \leftarrow \nabla_\theta \loss(\theta_{t-1})$
\STATE $v_t \leftarrow \xi \cdot \sum_i l_{t,i}\,(\gamma^{-1}\vecb{l}_t)_i$
    \hfill{\footnotesize\textit{// trace statistic}}
\STATE $\bar{v}_t \leftarrow \beta\,\bar{v}_{t-1} + (1-\beta)\,v_t$
    \hfill{\footnotesize\textit{// denominator EMA}}
\STATE $\hat{v}_t \leftarrow \bar{v}_t / (1 - \beta^t)$
    \hfill{\footnotesize\textit{// bias correction}}
\STATE $r_t \leftarrow 1/(1 + |\hat{v}_t|)$
    \hfill{\footnotesize\textit{// damping factor}}
\STATE $\vecb{m}_t \leftarrow \beta_m\,\vecb{m}_{t-1} + (1-\beta_m)\,\vecb{l}_t$
    \hfill{\footnotesize\textit{// momentum}}
\STATE $\hat{\vecb{m}}_t \leftarrow \gamma^{-1}\vecb{m}_t / (1 - \beta_m^t)$
    \hfill{\footnotesize\textit{// bias-corrected, metric-raised}}
\STATE $\theta_t \leftarrow \theta_{t-1} - \eta\,r_t\,\hat{\vecb{m}}_t + \lambda\,\theta_{t-1}$
\ENDWHILE
\RETURN $\theta_t$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Fixed diagonal metric (log-loss embedding, $f=\log\loss$, requires $\loss>0$)}
\label{alg:fixed-log}
\begin{algorithmic}[1]
\REQUIRE same as Algorithm~\ref{alg:fixed}
\STATE Initialise $t \leftarrow 0$, $\vecb{m}_0 \leftarrow \vecb{0}$, $\bar{v}_0 \leftarrow 0$
\WHILE{$\theta_t$ not converged}
\STATE $t \leftarrow t + 1$
\STATE $\vecb{l}_t \leftarrow \nabla_\theta \loss(\theta_{t-1})$
\STATE $L_t \leftarrow \loss(\theta_{t-1})$
\STATE $v_t \leftarrow \xi \cdot \sum_i l_{t,i}\,(\gamma^{-1}\vecb{l}_t)_i$
\STATE $\bar{v}_t \leftarrow \beta\,\bar{v}_{t-1} + (1-\beta)\,v_t$
\STATE $\hat{v}_t \leftarrow \bar{v}_t / (1 - \beta^t)$
\STATE $r_t \leftarrow L_t / (L_t^2 + |\hat{v}_t|)$
    \hfill{\footnotesize\textit{// log-loss damping}}
\STATE $\vecb{m}_t \leftarrow \beta_m\,\vecb{m}_{t-1} + (1-\beta_m)\,\vecb{l}_t$
\STATE $\hat{\vecb{m}}_t \leftarrow \gamma^{-1}\vecb{m}_t / (1 - \beta_m^t)$
\STATE $\theta_t \leftarrow \theta_{t-1} - \eta\,r_t\,\hat{\vecb{m}}_t + \lambda\,\theta_{t-1}$
\ENDWHILE
\RETURN $\theta_t$
\end{algorithmic}
\end{algorithm}

\noindent
In short, the practical update at each step is
\begin{equation}\label{eq:fixed-update}
    \delta\theta^i = -\eta\,r_t\,\hat{m}^i, \qquad
    r_t = \frac{1}{1 + |\hat{v}_t|}, \qquad
    v_t = \xi\,\gamma^{mn}\,l_{t,m}\,l_{t,n},
\end{equation}
where $\hat{v}_t$ is the bias-corrected EMA of $v_t$
(lines~5--8 of Algorithm~\ref{alg:fixed})
and $\hat{m}^i$ is the bias-corrected, metric-raised momentum (line~10).

\subsection{Log-Loss Variant}

\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable, title=\textbf{Log-Loss Derivation Sketch}, coltitle=black]
    With $f = \log\loss$ the embedding gradient is $\partial f/\partial\theta^i = l_i/\loss$,
    so the induced metric becomes
    $g_{ij} = \gamma_{ij} + \xi\,(l_i/\loss)(l_j/\loss)$.
    Applying Sherman-Morrison-Woodbury gives the inverse metric
    $$
        g^{ij} = \gamma^{ij} - \frac{\xi\,l^i l^j}{\loss^2 + \xi\,l_k l^k}.
    $$
    Contracting with the \emph{raw} gradient $l_j$ yields
    $g^{ij}l_j = l^i \cdot \loss^2/(\loss^2 + v_t)$,
    where $v_t = \xi\,\gamma^{mn}\,l_m\,l_n$.

    \medskip\noindent
    The full geometric update, however, uses the embedding gradient
    $\partial_j f = l_j/\loss$, not the raw gradient:
    $$
        g^{ij}\frac{\partial f}{\partial\theta^j}
        = \frac{g^{ij}l_j}{\loss}
        = l^i \cdot \frac{\loss}{\loss^2 + v_t}.
    $$
    The practical damping factor $r_t = \loss_t/(\loss_t^2 + |\hat{v}_t|)$
    (line~7 of Algorithm~\ref{alg:fixed-log})
    therefore follows directly from the geometry of the log embedding.
    This provides stronger damping than $\loss^2/(\loss^2 + |\hat{v}_t|)$
    as $\loss\to 0$, preventing overshooting near minima.
\end{tcolorbox}

\noindent In practice, the update direction $\vecb{r}$ and the metric direction $\vecb{l}$
need not coincide; see Section~\ref{sec:shared} for the full treatment.

\section{Learnable Scalar Metric}\label{sec:scalar}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

The fixed diagonal variant treats $\gamma$ as a hyperparameter chosen before training.
A natural next step is to let the metric adapt during optimisation.
We begin with the simplest case: a single learnable scalar
that controls the global scale of $\gamma^{-1}$.

\subsection{Construction}
We parameterise the inverse metric as $$
    \gamma^{ij} = \alpha\,\delta^{ij}, \qquad \alpha = e^s,
$$ where $s\in\mathbb{R}$ is a single learnable scalar.
(We learn the \emph{inverse} metric directly because the update rule requires $\gamma^{-1}$.)
Initialising $s=0$ gives $\gamma^{-1}=\Id_N$, so the optimiser starts as the unscaled fixed diagonal variant.

The ambient metric remains block-diagonal, $$
    h = \begin{pmatrix} e^{-s}\,\Id_N & \vecb{0} \\ \vecb{0}^\top & 1 \end{pmatrix},
$$ and the induced metric on parameter space is $$
    g_{ij} = e^{-s}\,\delta_{ij} + l_i l_j.
$$
Applying the Sherman-Morrison-Woodbury formula with $A_{ij}=e^{-s}\delta_{ij}$, $u=v=\vecb{l}$:
\begin{equation}\label{eq:scalar-inverse}
    g^{ij}
    = \gamma^{ij} - \frac{\gamma^{ik}l_k\;\gamma^{jl}l_l}{1 + \gamma^{mn}l_m l_n}
    = e^s\,\delta^{ij} - \frac{e^{2s}\,l_i\,l_j}{1 + e^s\|\vecb{l}\|^2}.
\end{equation}
The parameter update is therefore
\begin{equation}\label{eq:scalar-theory}
    \delta\theta^i
    = -\eta\,g^{ij}l_j
    = -\frac{\eta\,\gamma^{ij}l_j}{1 + \gamma^{mn}l_m l_n}
    = -\frac{\eta\,e^s\,l_i}{1 + e^s\|\vecb{l}\|^2}.
\end{equation}
The denominator depends on $s$ through $\gamma^{mn} = e^s\delta^{mn}$.
Figure~\ref{fig:step-scalar} shows how varying $s$ reshapes the step-size profile
relative to the fixed diagonal case (Figure~\ref{fig:step-fixed}).

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.75\textwidth]{../images/step_profile_scalar.png}
    \caption{Step-size profile for the learnable scalar metric:
    $\delta\theta^i/\eta = -e^s l_i/(1 + \xi\,e^s\,l_i^2)$
    in the single-parameter case ($N=1$, $\xi=1$).
    Increasing $s$ amplifies the peak step size and shifts it toward smaller gradients;
    decreasing $s$ flattens the curve, approaching plain SGD.
    The dashed line is the fixed diagonal baseline ($s=0$).}
    \label{fig:step-scalar}
\end{figure}

\noindent
The practical update follows the same structure as \eqref{eq:fixed-update},
with $\gamma^{ij} = \alpha\,\delta^{ij}$ and the trace statistic specialised to
\begin{equation}\label{eq:scalar-update}
    v_t = \xi\,\alpha\,\|\vecb{l}_t\|^2.
\end{equation}

\subsection{Metric Learning}\label{sec:scalar-learning}
We want to learn $s$ so that $\alpha = e^s$ is calibrated to the local geometry of the loss.
The trace statistic $v_t = \xi\alpha\|\vecb{l}_t\|^2$ appears directly in the denominator
of the update rule through $r_t = 1/(1+|\hat{v}_t|)$.
When $v_t$ is near zero the damping is inactive and the optimiser reduces to scaled SGD;
when $v_t$ is large the damping dominates and the geometric clipping is fully engaged.
We adapt $s$ by performing \emph{gradient ascent} on $v_t$ with respect to $s$.
This is a convenient heuristic---$v_t$ is the quantity that already appears in the denominator,
and ascent on it has a clear geometric interpretation (see below)---but
we do not claim it is the unique or optimal choice of surrogate.
Concretely:
$$
    \frac{\partial v_t}{\partial s} = \xi\,e^s\,\|\vecb{l}_t\|^2 = v_t.
$$

\paragraph{Why ascent?}
Consider a single parameter with $\gamma=1$.
The effective step size per unit gradient is
\begin{equation}\label{eq:step-per-grad}
    \frac{|\delta\theta|}{|l|} = \frac{e^s}{1 + \xi\,e^s\,l^2}.
\end{equation}
Its derivative with respect to the metric parameter $s$ is
\begin{equation}\label{eq:step-deriv}
    \frac{\partial}{\partial s}\!\left(\frac{e^s}{1 + \xi\,e^s\,l^2}\right)
    = \frac{e^s}{(1 + \xi\,e^s\,l^2)^2} > 0.
\end{equation}
The step size is therefore \emph{monotonically increasing} in $s$
(note: increasing in $s$, not in $l$),
bounded above by $1/(\xi\,l^2)$.
Gradient ascent on $v$ increases $s$, pushing the step size toward this
upper bound---the regime where the geometric clipping is most active.
Gradient \emph{descent} would decrease $s$, collapsing the step size toward zero
and disabling the metric entirely.
The regularisation term (below) provides a restoring force,
and the equilibrium between ascent and regularisation determines the operating point.

\paragraph{Regularisation and stability.}
Since $v_t\ge 0$, the unregularised ascent rule monotonically increases~$s$.
Three mechanisms keep $s$ bounded:
(i)~an L2 regularisation term $-\mu\lambda_s s$ that pulls $s$ back towards zero (i.e.\ $\gamma^{-1}=\Id$),
(ii)~hard clipping of $s$ to $[-s_{\max}, s_{\max}]$, and
(iii)~the denominator EMA, which smooths transient gradient spikes.

The online metric update is
\begin{equation}\label{eq:scalar-meta}
    s \;\leftarrow\; s + \mu\,v_t - \mu\,\lambda_s\,s,
\end{equation}
where $\mu>0$ is the metric learning rate and $\lambda_s>0$ is the L2 regularisation coefficient,
followed by clipping to $[-s_{\max}, s_{\max}]$.

\subsection{Algorithm}

\begin{algorithm}[H]
\caption{Learnable scalar metric (plain embedding)}
\label{alg:scalar}
\begin{algorithmic}[1]
\REQUIRE all hyperparameters from Algorithm~\ref{alg:fixed},
plus metric learning rate $\mu$, metric regularisation $\lambda_s$, clipping bound $s_{\max}$
\STATE Initialise $t \leftarrow 0$, $\vecb{m}_0 \leftarrow \vecb{0}$, $\bar{v}_0 \leftarrow 0$, $s \leftarrow 0$
\WHILE{$\theta_t$ not converged}
\STATE $t \leftarrow t + 1$
\STATE $\alpha \leftarrow e^s$
\STATE $\vecb{l}_t \leftarrow \nabla_\theta \loss(\theta_{t-1})$
\STATE $v_t \leftarrow \xi\,\alpha\,\|\vecb{l}_t\|^2$
\STATE $\bar{v}_t \leftarrow \beta\,\bar{v}_{t-1} + (1-\beta)\,v_t$
\STATE $\hat{v}_t \leftarrow \bar{v}_t / (1-\beta^t)$
\STATE $r_t \leftarrow 1/(1+|\hat{v}_t|)$
\STATE $\vecb{m}_t \leftarrow \beta_m\,\vecb{m}_{t-1} + (1-\beta_m)\,\vecb{l}_t$
\STATE $\hat{\vecb{m}}_t \leftarrow \alpha\,\vecb{m}_t/(1-\beta_m^t)$
\STATE $\theta_t \leftarrow \theta_{t-1} - \eta\,r_t\,\hat{\vecb{m}}_t + \lambda\,\theta_{t-1}$
    \hfill{\footnotesize\textit{// parameter update}}
\STATE $s \leftarrow s + \mu\,v_t - \mu\,\lambda_s\,s$
    \hfill{\footnotesize\textit{// metric update}}
\STATE $s \leftarrow \operatorname{clip}(s,\,-s_{\max},\,s_{\max})$
\ENDWHILE
\RETURN $\theta_t$
\end{algorithmic}
\end{algorithm}

The log-loss variant replaces line~6 with
$r_t \leftarrow L_t/(L_t^2 + |\hat{v}_t|)$.

The learnable scalar variant introduces three new hyperparameters beyond those of the fixed diagonal variant:
\begin{itemize}

    \item $\lambda_s$ (\texttt{metric\_reg}): L2 regularisation strength on $s$, controlling how far the metric drifts from identity.
    \item $s_{\max}$ (\texttt{metric\_clip}): clipping bound on $s$, bounding $\alpha\in[e^{-s_{\max}}, e^{s_{\max}}]$.
\end{itemize}

\section{Learnable Diagonal Metric}\label{sec:diag}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

The learnable scalar metric has a single degree of freedom and therefore applies
the same scale to every parameter.
We now generalise to a per-parameter learnable scale,
giving each parameter its own adaptive metric entry.

\subsection{Construction}
We promote $s$ to a full vector $\vecb{s}\in\mathbb{R}^N$ with one entry per parameter,
giving the per-parameter inverse metric $$
    \gamma^{ij} = e^{s_i}\,\delta^{ij}.
$$
The ambient metric is $$
    h = \begin{pmatrix} \operatorname{diag}(e^{-\vecb{s}}) & \vecb{0} \\ \vecb{0}^\top & 1 \end{pmatrix},
$$ and the induced metric on parameter space is $$
    g_{ij} = e^{-s_i}\,\delta_{ij} + l_i l_j.
$$
This is again a rank-1 update to a diagonal matrix.
Applying Sherman-Morrison-Woodbury with $A_{ij} = e^{-s_i}\delta_{ij}$ and $u=v=\vecb{l}$,
$$
    g^{ij} = e^{s_i}\,\delta^{ij} - \frac{l^i\,l^j}{1 + l_k l^k},
$$
where $l^i = \gamma^{ij}l_j = e^{s_i}l_i$ (no sum on $i$),
so $l^i l^j = e^{s_i}l_i\cdot e^{s_j}l_j$ and $l_k l^k = \sum_k e^{s_k}l_k^2$.
The update is
\begin{equation}\label{eq:diag-theory}
    \delta\theta^i
    = -\eta\,g^{ij}l_j
    = -\eta\left(l^i - \frac{l^i\,(l_k l^k)}{1+l_k l^k}\right)
    = -\frac{\eta\,l^i}{1+l_k l^k}.
\end{equation}
With $\xi$, momentum, and the EMA damping, the practical update is
\begin{equation}\label{eq:diag-update}
    \delta\theta^i = -\eta\,r_t\,\hat{m}^i, \qquad
    r_t = \frac{1}{1 + |\hat{v}_t|}, \qquad
    v_t = \xi\sum_k e^{s_k}\,l_k^2,
\end{equation}
with the same log-loss variant as before.
Compared to the scalar case, each parameter $\theta^i$ now has an individual scale $e^{s_i}$,
allowing the metric to adapt separately to different regions of parameter space.

\subsection{Metric Learning}
The per-parameter metric update treats each $s_i$ independently.
We use the same surrogate-ascent strategy as in Section~\ref{sec:scalar-learning},
now applied to the trace statistic $v_t = \xi\sum_k e^{s_k}l_k^2$
which serves as the surrogate objective:
$$
    J(\vecb{s}) = v_t = \xi\sum_k e^{s_k}\,l_k^2.
$$
This is the quantity that appears in the denominator of the update rule,
so adapting $\vecb{s}$ to calibrate $v_t$ keeps the damping in a useful operating range
(see Section~\ref{sec:scalar-learning} for the detailed argument).
Its gradient with respect to $s_i$ is $$
    \frac{\partial J}{\partial s_i} = \xi\,e^{s_i}\,l_i^2.
$$
The online update is therefore
\begin{equation}\label{eq:diag-meta}
    s_i \;\leftarrow\; s_i + \mu\,\xi\,e^{s_i}\,l_i^2 - \mu\,\lambda_s\,s_i,
\end{equation}
followed by mean-centering and clipping (discussed below).
The motivation for gradient \emph{ascent} (not descent) and the role of regularisation
are the same as in Section~\ref{sec:scalar-learning}.

\subsection{Mean-Centering}\label{sec:mean-center}

\paragraph{Parameter tensors and leaves.}
A model's parameters are organised as a collection of tensors
(e.g.\ one weight matrix and one bias vector per layer).
Each such tensor is called a \emph{leaf}.
We write $N_\ell$ for the number of scalar entries in a single leaf,
as distinct from the total parameter count $N = \sum_\ell N_\ell$.

\paragraph{The centering operation.}
The vector $\vecb{s}$ has one entry per parameter, $i=1,\ldots,N$.
After the gradient step \eqref{eq:diag-meta}, we mean-centre $\vecb{s}$
\emph{within each leaf independently}:
for each leaf $\ell$ containing parameters $i\in I_\ell$ (with $|I_\ell| = N_\ell$),
$$
    s_i \;\leftarrow\; s_i - \bar{s}_\ell, \qquad \bar{s}_\ell = \frac{1}{N_\ell}\sum_{k\in I_\ell} s_k.
$$
This is not an ad-hoc trick but a principled normalisation arising from a gauge degeneracy.

\paragraph{Gauge degeneracy.}
Write each log-scale as a mean plus a deviation: $s_k = \bar{s} + \delta_k$.
By construction $\sum_k \delta_k = \sum_k(s_k - \bar{s}) = N_\ell\bar{s} - N_\ell\bar{s} = 0$.
The trace statistic then factorises as
$$
    v = \xi\sum_k e^{s_k}l_k^2
      = \xi\,e^{\bar{s}}\sum_k e^{\delta_k}l_k^2.
$$
The global mean $\bar{s}$ acts as a multiplicative prefactor that is exactly degenerate with $\xi$:
shifting all $s_k$ by a constant $c$ is equivalent to scaling $\xi$ by $e^c$ and leaving $\vecb{s}$ unchanged.
Mean-centering enforces $\bar{s}=0$
(note: subsequent clipping may re-introduce a small nonzero mean),
which fixes this gauge and ensures that $\xi$ remains the single scalar controlling the overall metric magnitude while $\vecb{s}$ captures only the \emph{relative} per-parameter geometry.
Since we apply this per leaf rather than globally, a separate mean mode is removed in each parameter tensor.

\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable, title=\textbf{Fixed Diagonal as a Special Case}, coltitle=black]
    In a highly symmetric special case: if all $s_i$ are initialised to the same value
    and the gradients have the same magnitude for all parameters at every step,
    then $\vecb{s}$ stays uniform and mean-centering keeps it at zero.
    In that case $e^{s_i}=1$ for all $i$ and $v = \xi\|\vecb{l}\|^2$, which reduces exactly
    to the fixed diagonal variant with $\gamma=\Id_N$.
    The learnable diagonal metric therefore generalises fixed diagonal
    by learning \emph{relative} per-parameter scalings, while
    mean-centering intentionally removes the global scale mode
    (which is degenerate with $\xi$).
    To recover a learnable global scale, disable mean-centering
    or make $\xi$ itself learnable.
\end{tcolorbox}

    \caption{Evolution of per-parameter log-scales $s_i$ during training

    Different parameters acquire different scales:
    some are upscaled ($s_i>0$), others downscaled ($s_i<0$).

\begin{algorithm}[H]
\caption{Learnable diagonal metric (plain embedding)}
\label{alg:diag}
\begin{algorithmic}[1]
\REQUIRE all hyperparameters from Algorithm~\ref{alg:fixed},
plus $\mu$, $\lambda_s$, $s_{\max}$
\STATE Initialise $t \leftarrow 0$, $\vecb{m}_0 \leftarrow \vecb{0}$, $\bar{v}_0 \leftarrow 0$, $\vecb{s} \leftarrow \vecb{0}$
\WHILE{$\theta_t$ not converged}
\STATE $t \leftarrow t + 1$
\STATE $\vecb{l}_t \leftarrow \nabla_\theta \loss(\theta_{t-1})$
\STATE $v_t \leftarrow \xi\sum_k e^{s_k}\,l_{t,k}^2$
\STATE $\bar{v}_t \leftarrow \beta\,\bar{v}_{t-1} + (1-\beta)\,v_t$
\STATE $\hat{v}_t \leftarrow \bar{v}_t / (1-\beta^t)$

\STATE $\theta_t \leftarrow \theta_{t-1} - \eta\,r_t\,\hat{\vecb{m}}_t + \lambda\,\theta_{t-1}$

\end{algorithmic}
\end{algorithm}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Off-Diagonal Metric}\label{sec:offdiag}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

All preceding variants use an ambient metric $h$ whose off-diagonal blocks
(between the $N$ parameter dimensions and the single loss dimension) are zero.
We now explore what happens when those blocks are nonzero---a direction explicitly
suggested by~\cite{harvey2025}.

\subsection{Derivation}

Consider a more general ambient bilinear form $$
    h = \begin{pmatrix} \gamma & \vecb{a} \\ \vecb{b}^\top & 1 \end{pmatrix}\in\mathbb{R}^{(N+1)\times(N+1)}
$$ where $\vecb{a},\vecb{b}\in\mathbb{R}^N$.
Intuitively, the vectors $\vecb{a}$ and $\vecb{b}$ introduce off-diagonal couplings between the parameter space and the loss function dimension.
In general, if $\vecb{a}\neq \vecb{b}$ this $h$ is not symmetric, so here we simply treat it as a preconditioning matrix rather than a Riemannian metric.

\paragraph{Stability note.}
If the effective preconditioner is non-symmetric ($\vecb{a}\neq\vecb{b}$),
the update direction need not be a descent direction even for convex objectives.
To see why, note that a preconditioned gradient step $\delta\theta = -\eta\,P\,\nabla\loss$
is a descent direction only if $\nabla\loss^\top P\,\nabla\loss > 0$,
which is guaranteed when $P$ is positive-definite (or has positive-definite symmetric part).
A non-symmetric $h$ can produce a non-symmetric~$P = g^{-1}$,
for which the quadratic form $\nabla\loss^\top P\,\nabla\loss$ can be negative---meaning
the update moves \emph{uphill}.
We therefore recommend defaulting to the symmetric case $\vecb{a}=\vecb{b}$;
if using $\vecb{a}\neq\vecb{b}$, consider symmetrising the effective preconditioner
or otherwise enforcing positive-definiteness.

\medskip\noindent
The induced bilinear form on the parameter space is
\begin{align*}
    g_{ij}
    &= h_{\alpha\beta} \frac{\partial \phi^\alpha}{\partial \theta^i} \frac{\partial \phi^\beta}{\partial \theta^j} \\
    &= \gamma_{ij} + \xi\!\left(a_i l_j + b_j l_i + l_i l_j\right).
\end{align*}
To compute the inverse $g^{ij}$, we notice that $g$ can be expressed as a rank-2 update to $\gamma$:
for $U=[\vecb{a}, \vecb{l}]$, $V=[\vecb{l}, \vecb{b} + \vecb{l}]\in\mathbb{R}^{N\times 2}$ we have
\begin{align*}
    \gamma_{ij} + \xi\,U_{ik} V_{jk}
    &= \gamma_{ij} + \xi\!\left(a_i l_j + (b_j + l_j) l_i\right) \\
    &= \gamma_{ij} + \xi\!\left(a_i l_j + b_j l_i + l_i l_j\right) \\
    &= g_{ij}.
\end{align*}
Applying the Sherman-Morrison-Woodbury formula to $g = \gamma + \xi\,UV^\top$:
\begin{align*}
    g^{ij}
    &= \gamma^{ij} - \xi\,\gamma^{ik} U_{k\alpha} \Big(\delta_{\alpha\beta} + \xi\,V_{m\alpha} \gamma^{mn} U_{n\beta}\Big)^{-1} V_{l\beta} \gamma^{lj}.
\end{align*}
For convenience we define the scalar contractions $$
    c_{al} \coloneqq a_n l^n,\quad
    c_{ll} \coloneqq l_n l^n,\quad
    c_{ba} \coloneqq b_n a^n,\quad
    c_{bl} \coloneqq b_n l^n,
$$ so that the $2\times 2$ core matrix is $$
    \Id_2 + \xi\,V^\top\gamma^{-1}U
    = \begin{pmatrix}
            1 + \xi\,c_{al} & \xi\,c_{ll} \\
            \xi\,(c_{ba}\!+\!c_{al}) & 1 + \xi\,(c_{bl}\!+\!c_{ll})
       \end{pmatrix}
$$ with determinant
\begin{equation}\label{eq:offdiag-det}
    D
    = 1 + \xi\!\left(c_{al} + c_{bl} + c_{ll}\right) + \xi^2\!\left(c_{al}\,c_{bl} - c_{ll}\,c_{ba}\right).
\end{equation}
Inverting the $2\times 2$ system and contracting yields the parameter update
\begin{equation}\label{eq:offdiag-update}
    \delta\theta^i
    = -\eta\, g^{ij} l_j
    = -\eta\left[ \frac{1 + \xi\,c_{al}}{D}\,l^i - \frac{\xi\,c_{ll}}{D}\,a^i \right].
\end{equation}
The closed-form inverse requires $D\neq 0$
(equivalently, $\det(\Id_2 + \xi\,V^\top\gamma^{-1}U)\neq 0$).
The JAX implementation includes a near-singular fallback;
the PyTorch implementation solves the $2\times 2$ system directly via
\texttt{torch.linalg.solve}.

\begin{sloppypar}
A numerical check of this has been performed in
\href{https://github.com/Noah-Everett/Induced-Metric-Optimiser/blob/main/documents/off-diag-check.ipynb}{documents/off-diag-check.ipynb}:
for random $\vecb{a},\vecb{b},\gamma,\vecb{l}$ the closed-form $g^{ij}l_j$ matches
\texttt{torch.linalg.solve}$(g,\vecb{l})$ within floating-point tolerance.
\end{sloppypar}

\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable, title=\textbf{Sanity Checks}, coltitle=black]
    \textbf{Diagonal recovery} ($\vecb{a}=\vecb{b}=\vecb{0}$):
    $c_{al} = c_{ba} = c_{bl} = 0$, so $D = 1 + \xi\,c_{ll}$.
    Equation~\eqref{eq:offdiag-update} gives
    $\delta\theta^i = -\eta\,l^i/(1 + \xi\,c_{ll})$,
    which matches the fixed diagonal case. \checkmark

    \medskip\noindent
    \textbf{Symmetric coupling} ($\vecb{a}=\vecb{b}=\vecb{l}$):
    $c_{al}=c_{bl}=c_{ba}=c_{ll}$,
    so $D = 1 + 3\xi\,c_{ll} + \xi^2(c_{ll}^2 - c_{ll}^2) = 1+3\xi\,c_{ll}$.
    The update simplifies to
    $\delta\theta^i = -\eta\,l^i/(1+3\xi\,c_{ll})$. \checkmark

    \medskip\noindent
    \textbf{One-sided coupling} ($\vecb{a}=\vecb{0}$, $\vecb{b}\neq\vecb{0}$):
    $c_{al}=c_{ba}=0$, $D = 1 + \xi(c_{bl} + c_{ll})$.
    The update reduces to $\delta\theta^i = -\eta\,l^i/D$,
    i.e.\ a scaled gradient step whose denominator depends on $\vecb{b}$ through $c_{bl}$.
\end{tcolorbox}

\noindent
The update direction \eqref{eq:offdiag-update} has two components:
one along $l^i$ (the gradient direction) and one along $a^i$ (the off-diagonal coupling direction).
Depending on the choices of $\vecb{a}$ and $\vecb{b}$, this can lead to a variety of behaviours:
\begin{itemize}
    \item If $\vecb{a}=\vecb{0}$ or $\vecb{a}\propto \vecb{l}$: plain gradient descent with an adaptive learning rate.
    \item If $\vecb{a}=\text{momentum}$: a momentum-like update with an adaptive learning rate.
    \item If $\vecb{a}=\vecb{\theta}$ (the parameter vector): gradient descent combined with a form of
    geometry-induced weight decay or growth, depending on the sign of $\xi\,c_{ll}/D$.
\end{itemize}

\subsection{Algorithm}

\begin{algorithm}[H]
\caption{Off-diagonal metric}
\label{alg:offdiag}
\begin{algorithmic}[1]
\REQUIRE learning rate $\eta$, momentum decay $\beta_m$, metric strength $\xi$, weight decay $\lambda$,
inverse base metric $\gamma^{-1}$, mode choices for $\vecb{a}$, $\vecb{b}$, $\vecb{l}$, $\vecb{r}$
\STATE Initialise $t \leftarrow 0$, $\vecb{m}_0 \leftarrow \vecb{0}$
\WHILE{$\theta_t$ not converged}
\STATE $t \leftarrow t + 1$
\STATE $\vecb{g}_t \leftarrow \nabla_\theta \loss(\theta_{t-1})$
\STATE $\vecb{m}_t \leftarrow \beta_m\,\vecb{m}_{t-1} + (1-\beta_m)\,\vecb{g}_t$;\quad
  $\hat{\vecb{m}}_t \leftarrow \vecb{m}_t/(1-\beta_m^t)$
\STATE Select $\vecb{a}$, $\vecb{b}$, $\vecb{l}$, $\vecb{r}$ from modes (gradient, momentum, $\theta$, or $\vecb{0}$)
\STATE $U \leftarrow (\vecb{a},\,\vecb{l})$;\quad $V \leftarrow (\vecb{l},\,\vecb{b}+\vecb{l})$
\STATE Compute $c_{al}$, $c_{ll}$, $c_{ba}$, $c_{bl}$ and $D$ via \eqref{eq:offdiag-det}
\STATE Compute $G^{-1}\vecb{r}$ via Woodbury ($2\times 2$ solve + $O(N)$ vector ops)
\STATE $\theta_t \leftarrow \theta_{t-1} - \eta\,(G^{-1}\vecb{r}) + \lambda\,\theta_{t-1}$
\ENDWHILE
\RETURN $\theta_t$
\end{algorithmic}
\end{algorithm}

\noindent
Note that Algorithm~\ref{alg:offdiag} does not use a denominator EMA ($\beta$):
the full $2\times 2$ Woodbury solve is applied directly at each step.

\paragraph{Computational cost.}
Taking $\gamma_{ij}=\gamma\,\delta_{ij}$ (scalar base metric) and writing $$
    G = \gamma\,\Id_N + \xi\,U V^\top, \qquad U = (\vecb{a},\,\vecb{l}), \qquad V = (\vecb{l},\,\vecb{b}+\vecb{l}),
$$ the Sherman-Morrison-Woodbury formula gives $$
    G^{-1}\vecb{r} = \frac{1}{\gamma}\vecb{r} - \frac{\xi}{\gamma^2}\,U\!\left(\Id_2 + \frac{\xi}{\gamma}V^\top U\right)^{-1}\!V^\top\vecb{r}.
$$ This costs $O(N)$: only inner products and a single $2\times 2$ matrix inversion are required, never a full $N\times N$ matrix.

\paragraph{Modes for $\vecb{l}$, $\vecb{a}$, and $\vecb{b}$.}
The vector $\vecb{l}$ encodes the direction along which the loss coordinate stretches, with two built-in choices:
\begin{itemize}
    \item \textbf{Gradient mode}: $\vecb{l}_i = \partial_i\loss$ --- the metric is shaped by the instantaneous slope.
    \item \textbf{Momentum mode}: $\vecb{l}_i = \vecb{m}_i$ --- the metric incorporates accumulated gradient history.
\end{itemize}
The off-diagonal coupling vectors $\vecb{a}$ and $\vecb{b}$ each support:
\begin{itemize}
    \item \textbf{Zero}: $\vecb{a}_i=0$ or $\vecb{b}_i=0$ --- eliminates one branch of the coupling.
    \item \textbf{Gradient}: aligned with $\partial_i\loss$.
    \item \textbf{Momentum}: aligned with $\vecb{m}_i$.
    \item \textbf{Parameter}: $\vecb{a}_i=\theta^i$ or $\vecb{b}_i=\theta^i$ --- couples geometry to position.
    \item \textbf{Same-as-$a$}: $\vecb{b}_i=\vecb{a}_i$ --- symmetric off-diagonal structure.
\end{itemize}
For full generality the implementations also accept user-provided vectors or callables.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\subsection{Update Direction vs.\ Metric Direction}
In all implementations, the goal is to realise $$
    \delta\theta^i = -\eta\, g^{ij} r_j,
$$ where $r_j$ is the \emph{update direction} and $l_i$ is the direction used to \emph{construct the metric}.
These need not be the same vector.
(Note that $r_j$ here is a vector, not to be confused with the scalar
damping factor $r_t$ in Sections~\ref{sec:fixed}--\ref{sec:diag};
the distinction is always clear from context and index type.)
In ordinary gradient descent one would take $r_j = l_j = \partial_j\loss$,
but we also test momentum-based choices.
The four combinations are:
\begin{itemize}
    \item $\vecb{l} = \nabla\loss,\; \vecb{r} = \nabla\loss$: pure geometric gradient descent.
    \item $\vecb{l} = \nabla\loss,\; \vecb{r} = \vecb{m}$: metric shaped by the instantaneous gradient, step along momentum.
    \item $\vecb{l} = \vecb{m},\; \vecb{r} = \nabla\loss$: metric shaped by accumulated history, step along raw gradient.
    \item $\vecb{l} = \vecb{m},\; \vecb{r} = \vecb{m}$: both metric and step are momentum-based.
\end{itemize}

\subsection{Computational Cost}
All variants are $O(N)$ per step (assuming scalar or diagonal $\gamma$) and never materialise a full $N\times N$ matrix:
\begin{center}
\small
\begin{tabular}{llc}
    \toprule
    \textbf{Variant} & \textbf{Dominant operation} & \textbf{Additional metric state} \\
    \midrule
    Fixed diagonal     & scalar $\times$ vector               & none \\
    Learnable scalar   & scalar $\times$ vector               & 1 float ($s$) \\
    Learnable diagonal & element-wise vector $\times$ vector  & $N$ floats ($\vecb{s}$) \\
    Off-diagonal       & inner products + $2\times2$ inverse  & none \\
    \bottomrule
\end{tabular}
\end{center}
The metric-learning overhead for the learnable variants is negligible compared to the forward and backward passes.

\subsection{Shared Hyperparameters}
The following hyperparameters are common to the fixed diagonal, learnable scalar, and learnable diagonal variants:
\begin{itemize}
    \item $\eta$ (\texttt{lr}): base learning rate.
    \item $\beta_m$ (\texttt{momentum}): EMA decay for the momentum buffer.
    (The paper~\cite{harvey2025} uses $\mu$ for this quantity; we write $\beta_m$ to avoid collision with the metric learning rate $\mu$.)
    \item $\xi$ (\texttt{xi}): strength of the induced metric correction.
    \item $\beta$ (\texttt{beta}): EMA decay for the denominator estimate $\hat{v}$.
    \item $\lambda$ (\texttt{weight\_decay}): decoupled weight decay ($\lambda\le 0$ for decay, following the convention of~\cite{harvey2025}).
\end{itemize}
The off-diagonal variant uses $\eta$, $\beta_m$, $\xi$, and $\lambda$ but does not use the denominator EMA $\beta$.
The learnable variants additionally require:
\begin{itemize}
    \item $\mu$ (\texttt{metric\_lr}): step size for the online metric update.
    \item $\lambda_s$ (\texttt{metric\_reg}): L2 regularisation on $s$ or $\vecb{s}$.
    \item $s_{\max}$ (\texttt{metric\_clip}): log-domain clipping bound on $s$,
    constraining $\alpha = e^s \in [e^{-s_{\max}},\,e^{s_{\max}}]$.
\end{itemize}

\section{Geodesic Convexity Analysis}\label{sec:geodesic}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
A natural question arises: does the induced metric
$g_{ij}=\gamma_{ij}+\xi\,l_i\,l_j$ make the loss landscape
``more convex'' in a geometric sense?
If so, the optimiser's convergence could be understood
through the lens of Riemannian optimisation theory,
and stronger guarantees might follow.

The answer turns out to be clean and somewhat surprising.
In this section we derive the \emph{Riemannian Hessian}
of $\loss$ with respect to $g$ in closed form and show that
it is a positive scalar multiple of the ordinary Hessian.
This means the metric preserves convexity rather than creating it,
but the scalar factor provides \emph{adaptive curvature damping} ---
exactly the smooth gradient clipping behaviour observed empirically.

All formulas below have been verified three ways:
(i)~abstractly for general~$N$ using the xAct tensor algebra system,
(ii)~by explicit symbolic computation in $n=2$ and $n=3$, and
(iii)~numerically on the benchmark test functions.
The full verification notebook is
\texttt{documents/geodesic-convexity-analysis.nb}.

\subsection{Background: Geodesic Convexity}\label{sec:geodesic-bg}

Recall that in standard optimisation a function $\loss$ is convex
if its Hessian $H_{ij} = \partial_i\partial_j\loss$ is positive semi-definite
everywhere.
The Riemannian generalisation replaces the Euclidean Hessian
with the \emph{Riemannian Hessian} (also called the covariant Hessian):
\begin{equation}\label{eq:riem-hess-def}
    (\operatorname{Hess}_g\loss)_{ij}
    = \nabla_i\nabla_j\loss
    = \partial_i\partial_j\loss - \Gamma^k_{ij}\,\partial_k\loss
    = H_{ij} - \Gamma^k_{ij}\,l_k.
\end{equation}
Here $\Gamma^k_{ij}$ are the \textbf{Christoffel symbols} of $g$,
which encode how the metric's coordinate basis twists as one moves
through parameter space.
For a flat (constant) metric the Christoffel symbols vanish and
the Riemannian Hessian reduces to the ordinary Hessian.
For a curved metric they introduce a \emph{correction term}
$\Gamma^k_{ij}\,l_k$ that subtracts curvature effects from $H$.

\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable,
  title=\textbf{Geodesic Convexity}, coltitle=black]
A function $\loss$ is \emph{geodesically convex} with respect to
a Riemannian metric $g$ if
$\operatorname{Hess}_g\loss \succeq 0$ everywhere.
If $\loss$ is geodesically convex w.r.t.\ $g$, then Riemannian
gradient descent
$\delta\theta^i = -\eta\,g^{ij}l_j$
is guaranteed to converge to a global minimum ---
even if $\loss$ is non-convex in the ordinary Euclidean sense.
\end{tcolorbox}

\noindent
The key question is therefore: can choosing $g = \gamma + \xi\,l\otimes l$
make the correction term $\Gamma^k_{ij}\,l_k$ large enough to
cancel negative eigenvalues of $H$ and produce a PSD Riemannian Hessian?

\subsection{Christoffel Symbols}\label{sec:christoffel}

The Christoffel symbols of the Levi-Civita connection
for a metric $g$ are defined by
\begin{equation}\label{eq:christoffel}
    \Gamma^k_{ij}
    = \frac{1}{2}\,g^{kl}\bigl(
        \partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij}
      \bigr).
\end{equation}
We compute this in three steps: differentiate the metric,
simplify the bracket, and contract with the inverse metric.

\paragraph{Step 1: Metric derivatives.}
Since $\gamma$ is constant (parameter-independent), only the rank-one term
$\xi\,l_i\,l_j$ contributes.
Applying the product rule and using
$\partial_k l_i = \partial_k\partial_i\loss = H_{ki}$:
\begin{equation}\label{eq:dg}
    \partial_k g_{ij}
    = \xi\,\partial_k(l_i\,l_j)
    = \xi\bigl(H_{ki}\,l_j + l_i\,H_{kj}\bigr).
\end{equation}

\paragraph{Step 2: The Christoffel bracket.}
The combination inside the parentheses in \eqref{eq:christoffel}
is called the \emph{Christoffel bracket}.
Substituting \eqref{eq:dg} and writing all six terms explicitly:
\begin{align}
    &\partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij} \nonumber\\
    &= \xi\bigl[\,
      \underbrace{H_{ij}\,l_l + l_j\,H_{il}}_{\partial_i g_{jl}}
    + \underbrace{H_{ji}\,l_l + l_i\,H_{jl}}_{\partial_j g_{il}}
    - \underbrace{H_{li}\,l_j + l_i\,H_{lj}}_{\partial_l g_{ij}}
    \,\bigr]. \label{eq:bracket-expanded}
\end{align}
Now use the symmetry of the Hessian ($H_{ij}=H_{ji}$, $H_{il}=H_{li}$, $H_{jl}=H_{lj}$).
The cross-terms cancel pairwise:
$l_j H_{il} - H_{li} l_j = 0$ and $l_i H_{jl} - l_i H_{lj} = 0$.
What remains is:
\begin{equation}\label{eq:bracket}
    \boxed{\;
    \partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij}
    = 2\,\xi\,H_{ij}\,l_l.
    \;}
\end{equation}
This is the key simplification: the bracket is proportional to $H_{ij}$
times $l_l$, with all information about different index arrangements
absorbed by the Hessian symmetry.

\paragraph{Step 3: Contraction with the inverse metric.}
We need $g^{kl}\,l_l$, the gradient raised with $g$ (not $\gamma$).
Starting from the Sherman--Morrison inverse
$g^{kl} = \gamma^{kl} - \xi l^k l^l/(1+\xi\|l\|_\gamma^2)$:
\begin{align}
    g^{kl}\,l_l
    &= \gamma^{kl}\,l_l - \frac{\xi\,l^k\,l^l\,l_l}{1+\xi\,\|l\|_\gamma^2}
    = l^k - \frac{\xi\,l^k\,\|l\|_\gamma^2}{1+\xi\,\|l\|_\gamma^2}
    = l^k\left(1 - \frac{\xi\,\|l\|_\gamma^2}{1+\xi\,\|l\|_\gamma^2}\right) \nonumber\\
    &= \frac{l^k}{1+\xi\,\|l\|_\gamma^2}. \label{eq:ginv-l}
\end{align}
Combining Steps~1--3:
$\Gamma^k_{ij} = \frac{1}{2}\,g^{kl}\cdot 2\xi H_{ij}\,l_l
= \xi\,H_{ij}\,(g^{kl}\,l_l)$, giving
\begin{equation}\label{eq:chris-closed}
    \boxed{\;
    \Gamma^k_{ij}
    = \frac{\xi\,H_{ij}\,l^k}{1+\xi\,\|l\|_\gamma^2}
    \;}
\end{equation}
where $l^k=\gamma^{kk}l_k$ is the $\gamma$-raised gradient
and $\|l\|_\gamma^2=\gamma^{mn}l_m l_n$.

\paragraph{Sanity checks.}
\begin{itemize}[leftmargin=1.8em]
    \item \textbf{Symmetry:} $\Gamma^k_{ij} = \Gamma^k_{ji}$ since $H_{ij}=H_{ji}$.\ \checkmark
    \item \textbf{Flat limit:} when $\xi=0$, $\Gamma^k_{ij}=0$,
          recovering the flat connection of $\gamma$.\ \checkmark
    \item \textbf{Proportionality:}
          $\Gamma^k_{ij}$ is proportional to $H_{ij}$ for all $k$.
          This will drive the main result.
\end{itemize}

\subsection{Riemannian Hessian}\label{sec:riem-hess}

\paragraph{The correction term.}
Substituting \eqref{eq:chris-closed} into the correction
$\Gamma^k_{ij}\,l_k$:
\begin{equation}\label{eq:correction}
    \Gamma^k_{ij}\,l_k
    = \frac{\xi\,H_{ij}\,l^k\,l_k}{1+\xi\,\|l\|_\gamma^2}
    = \frac{\xi\,\|l\|_\gamma^2}{1+\xi\,\|l\|_\gamma^2}\;H_{ij}.
\end{equation}
The correction is proportional to $H_{ij}$ with scalar coefficient
$\xi\|l\|_\gamma^2/(1+\xi\|l\|_\gamma^2) \in [0,1)$.

\paragraph{Main result.}
The Riemannian Hessian~\eqref{eq:riem-hess-def}
becomes
\begin{align}
    (\operatorname{Hess}_g\loss)_{ij}
    &= H_{ij} - \frac{\xi\,\|l\|_\gamma^2}{1+\xi\,\|l\|_\gamma^2}\;H_{ij}
    = H_{ij}\left(1 - \frac{\xi\,\|l\|_\gamma^2}{1+\xi\,\|l\|_\gamma^2}\right),
\end{align}
and since $1 - \frac{\xi\,\|l\|^2}{1+\xi\,\|l\|^2}
= \frac{1}{1+\xi\,\|l\|^2}$, we obtain
\begin{equation}\label{eq:riem-hess}
    \boxed{\;
    (\operatorname{Hess}_g\loss)_{ij}
    = \frac{H_{ij}}{1+\xi\,\|l\|_\gamma^2}
    \;}
\end{equation}

\begin{tcolorbox}[colback=blue!4, colframe=blue!25, breakable,
  title=\textbf{Interpretation}, coltitle=black]
The Riemannian Hessian is the Euclidean Hessian divided by the
positive scalar $(1+\xi\|l\|_\gamma^2)$.
This is the same denominator that appears in the optimiser's
update rule \eqref{eq:fixed-theory}.
The metric does not rotate eigenvectors or mix curvature directions ---
it applies a uniform, position-dependent damping.
\end{tcolorbox}

\paragraph{Eigenvalue analysis.}
Let $\lambda_1,\ldots,\lambda_N$ be the eigenvalues of $H$.
Since $\operatorname{Hess}_g\loss = H/(1+\xi\|l\|_\gamma^2)$
is a scalar multiple, its eigenvalues are
$\lambda_k/(1+\xi\|l\|_\gamma^2)$ with the same eigenvectors.
The scaling factor $1/(1+\xi\|l\|_\gamma^2) \in (0,1]$ is strictly positive,
so:
\begin{enumerate}[leftmargin=1.8em]
    \item \textbf{Sign preservation.}
    Every eigenvalue keeps its sign:
    positive stays positive, negative stays negative, zero stays zero.
    \emph{The induced metric cannot flip a saddle direction into a convex one.}

    \item \textbf{Geodesic convexity $\Longleftrightarrow$ Euclidean convexity.}
    $\operatorname{Hess}_g\loss\succeq 0$ if and only if $H\succeq 0$.
    The rank-one induced metric cannot convert a non-convex function
    into a geodesically convex one, regardless of $\xi$.

    \item \textbf{Condition number is unchanged.}
    $\kappa(\operatorname{Hess}_g\loss) =
    \lambda_{\max}/\lambda_{\min} = \kappa(H)$:
    the uniform scaling cancels in the ratio.

    \item \textbf{Magnitude damping.}
    Although signs are preserved, \emph{all curvatures are damped}
    by a factor that depends on position:
    \begin{itemize}
        \item Far from critical points ($\|l\|$ large):
              damping is strong, $|\lambda_k| \to 0$.
        \item Near critical points ($\|l\|\to 0$):
              damping vanishes, $\operatorname{Hess}_g\loss \to H$.
    \end{itemize}
    The metric flattens the landscape in steep regions
    while preserving the full curvature near minima and saddle points.
\end{enumerate}

\paragraph{Worked example: quadratic loss.}
For $\loss(\theta) = \tfrac{1}{2}\theta^\top A\,\theta$ with
symmetric $A$, we have $H = A$ (constant),
$l = A\theta$, and $\|l\|^2 = \theta^\top A^\top A\,\theta$.
With $\gamma = \Id_N$:
\begin{equation}
    (\operatorname{Hess}_g\loss)_{ij}
    = \frac{A_{ij}}{1 + \xi\,\|A\theta\|^2}.
\end{equation}
Near the minimum $\theta=0$: $\|A\theta\|\to 0$, so
$\operatorname{Hess}_g\loss \to A$.
Far from the minimum: $\operatorname{Hess}_g\loss \to 0$,
regardless of whether $A$ is PSD or indefinite.
If $A$ has a negative eigenvalue (saddle), that eigenvalue remains
negative everywhere but is progressively damped away from the origin.

\subsection{Connection to the Gauss Equation}\label{sec:gauss}

The same results can be obtained from a complementary perspective:
the \emph{extrinsic geometry} of the loss surface.
This route gives additional insight and connects the Hessian
to curvature in a way that is geometrically transparent.

\paragraph{Setup.}
The embedding $\phi(\theta) = (\theta^1,\ldots,\theta^N,\loss(\theta))$
defines a hypersurface in $\mathbb{R}^{N+1}$.
The ambient metric is
$h=\operatorname{diag}(\gamma_1,\ldots,\gamma_N,\xi)$.
The tangent vectors are $e_i = (\delta_{i1},\ldots,\delta_{iN},\,l_i)$,
and the induced metric is $g_{ij} = h(e_i, e_j) = \gamma_{ij} + \xi\,l_i l_j$
as expected.

\paragraph{Unit normal.}
The unit normal $n$ (with respect to $h$) satisfies
$h(n,e_i)=0$ and $h(n,n)=1$.
Solving these constraints gives
\begin{equation}
    n = \frac{1}{\sqrt{\xi(1+\xi\|l\|_\gamma^2)}}
    \Bigl(-\xi\,l^1,\;\ldots,\;-\xi\,l^N,\;1\Bigr).
\end{equation}
We write $n_{N+1} \coloneqq 1/\sqrt{\xi(1+\xi\|l\|_\gamma^2)}$
for the component along the loss axis.

\paragraph{Second fundamental form.}
The second fundamental form measures how the surface curves
within the ambient space.
For our embedding, $\partial_i\partial_j\phi = (0,\ldots,0,\,H_{ij})$,
so
\begin{equation}\label{eq:sff}
    b_{ij}
    = h\bigl(\partial_i\partial_j\phi,\,n\bigr)
    = \xi\,n_{N+1}\,H_{ij}
    = \sqrt{\frac{\xi}{1+\xi\|l\|_\gamma^2}}\;H_{ij}.
\end{equation}
Like the Riemannian Hessian, $b_{ij}$ is proportional to $H_{ij}$.
The two are related by
\begin{equation}\label{eq:sff-hess}
    (\operatorname{Hess}_g\loss)_{ij} = n_{N+1}\,b_{ij},
\end{equation}
connecting the covariant Hessian to the extrinsic curvature of the
loss surface.

\paragraph{Gauss equation.}
For a hypersurface in a flat ambient space, the Gauss equation
expresses the intrinsic Riemann curvature tensor entirely in terms
of the second fundamental form:
\begin{equation}\label{eq:gauss}
    R_{ijkl}
    = b_{ik}\,b_{jl} - b_{il}\,b_{jk}
    = \frac{\xi}{1+\xi\|l\|_\gamma^2}
      \bigl(H_{ik}\,H_{jl} - H_{il}\,H_{jk}\bigr).
\end{equation}
This tensor inherits all the standard symmetries
(verified abstractly using xAct):
skew-symmetry in each index pair,
pair symmetry $R_{ijkl}=R_{klij}$,
and the first Bianchi identity
$R_{ijkl}+R_{iklj}+R_{iljk}=0$.

\paragraph{Gaussian curvature.}
For a 2D parameter space ($N=2$), the only independent component of
$R_{ijkl}$ is $R_{1212}$, and the Gaussian curvature is
\begin{equation}\label{eq:gauss-curv}
    K = \frac{R_{1212}}{\det(g)}
    = \frac{\xi\,\det(H)}{\det(\gamma)\,(1+\xi\|l\|_\gamma^2)^2}.
\end{equation}
The Ricci tensor satisfies $R_{ij} = K\,g_{ij}$ and the scalar
curvature is $R = 2K$, as expected for a surface.

\paragraph{Curvature--Hessian dictionary.}
Equation~\eqref{eq:gauss-curv} provides a direct link between the
intrinsic geometry of the parameter surface and the loss Hessian:
\begin{center}
\small
\begin{tabular}{@{}lll@{}}
    \toprule
    \textbf{Surface geometry} & \textbf{Condition} & \textbf{Hessian meaning} \\
    \midrule
    Positive curvature ($K>0$) & $\det(H)>0$ & $H$ definite (bowl or dome) \\
    Negative curvature ($K<0$) & $\det(H)<0$ & $H$ indefinite (saddle) \\
    Zero curvature ($K=0$)     & $\det(H)=0$ & $H$ singular (ridge/valley) \\
    \bottomrule
\end{tabular}
\end{center}
The magnitude of $K$ is controlled by $\xi$:
larger $\xi$ amplifies curvature near critical points ($\|l\|$ small)
and suppresses it in steep regions ($\|l\|$ large).

\subsection{Off-Diagonal Metric}\label{sec:geodesic-offdiag}

The off-diagonal metric of Section~\ref{sec:offdiag}
has the form
$g_{ij}=\gamma_{ij}+\xi(a_i l_j + b_j l_i + l_i l_j)$
with coupling vectors $a,b$.
A natural question is whether this richer structure
can achieve what the rank-one metric cannot.

\paragraph{Bracket derivation.}
With $a,b$ treated as constant vectors,
$\partial_k g_{ij} = \xi\bigl[(a_i+l_i)H_{kj} + (b_j+l_j)H_{ki}\bigr]$.
Writing $u_i \coloneqq a_i + l_i$ and $v_j \coloneqq b_j + l_j$
for brevity, the six bracket terms become:
\begin{align}
    &\partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij} \nonumber\\
    &= \xi\bigl[
      u_j H_{il} + v_l H_{ij}
    + u_i H_{jl} + v_l H_{ij}
    - u_i H_{lj} - v_j H_{li}
    \bigr] \nonumber\\
    &= \xi\bigl[
      (u_j - v_j) H_{il} + 2\,v_l\,H_{ij}
    \bigr] \label{eq:offdiag-bracket}\\
    &= \xi\Bigl[(a_j - b_j)\,H_{il} + 2(b_l + l_l)\,H_{ij}\Bigr]. \nonumber
\end{align}
Here we used $H_{jl}=H_{lj}$ and $H_{il}=H_{li}$ to cancel terms,
and substituted back $u-v = a-b$ and $v_l = b_l + l_l$.

\paragraph{Two cases.}
\begin{enumerate}[leftmargin=1.8em]
    \item \textbf{Symmetric case ($a=b$).}
    The $(a_j - b_j)$ term vanishes, leaving
    $2\xi(a_l+l_l)H_{ij}$ --- again proportional to $H_{ij}$.
    The Riemannian Hessian is a positive scalar multiple of $H$
    (with a different scalar from the rank-one case),
    and the same sign-preservation result holds.

    \item \textbf{Asymmetric case ($a\neq b$).}
    The term $(a_j-b_j)H_{il}$ mixes Hessian components in
    different index directions.
    The Riemannian Hessian correction is no longer proportional to $H$,
    and its eigenvalues can differ qualitatively from those of $H$.
    %
    A numerical scan over $\sim\!14{,}000$ configurations of
    $(a,b,l,\xi)$ with an indefinite $H$ found:
    \begin{itemize}
        \item \textbf{58 cases} where the Riemannian Hessian became PSD
              (saddle $\to$ geodesically convex).
        \item \textbf{But}: in all 58 cases the metric $g$ was \emph{not symmetric}
              ($g_{ij}\neq g_{ji}$), so $g$ is not a Riemannian metric.
    \end{itemize}
    The symmetry condition $g_{ij}=g_{ji}$ requires
    $a_i l_j + l_i b_j = a_j l_i + l_j b_i$ for all $i,j$,
    which holds if and only if $a=b$ (or $a-b \propto l$).
    A targeted scan over all symmetric off-diagonal configurations
    found \textbf{zero cases} where a saddle became convex.
\end{enumerate}

\begin{tcolorbox}[colback=gray!8, colframe=gray!22, breakable,
  title=\textbf{Summary: Geodesic Convexity and the Induced Metric},
  coltitle=black]
For any proper Riemannian metric in the induced-metric family
($g=\gamma + \xi\,l\otimes l$ or the symmetric off-diagonal case $a=b$),
the Riemannian Hessian is a positive scalar multiple of $H$.
\emph{Geodesic convexity is equivalent to Euclidean convexity.}
The metric cannot make a non-convex loss geodesically convex.

The asymmetric off-diagonal case ($a\neq b$) can change eigenvalue structure,
but the resulting $g$ is not symmetric and hence not a Riemannian metric.
The optimiser uses it as a preconditioner,
but classical Riemannian convergence guarantees do not apply.
\end{tcolorbox}

\subsection{Implications for the Optimiser}\label{sec:geodesic-implications}

The central result~\eqref{eq:riem-hess} shows that the induced metric
$g=\gamma+\xi\,l\otimes l$ provides an \emph{adaptive step-size rescaling}
rather than a curvature correction.
The parameter update~\eqref{eq:grad-flow},
\begin{equation}
    \delta\theta^i = -\eta\,g^{ij}\,l_j
    = -\eta\,\frac{l^i}{1+\xi\,\|l\|_\gamma^2},
\end{equation}
moves along the same direction as preconditioned gradient descent with $\gamma$,
but with the effective learning rate reduced by $1/(1+\xi\|l\|_\gamma^2)$.
This is precisely the ``smooth gradient clipping'' interpretation:
\begin{itemize}[leftmargin=1.8em]
    \item When $\|l\|\gg 1/\sqrt{\xi}$: the step size scales as $\sim 1/(\xi\|l\|)$,
    preventing large steps in steep regions.
    \item When $\|l\|\ll 1/\sqrt{\xi}$: the step size approaches the unscaled
    $\eta\,l^i$, allowing full steps near critical points where the gradient
    is informative.
\end{itemize}
Although this does not provide geodesic convexity for non-convex losses,
the curvature damping has practical benefits:
it improves training stability without distorting the local geometry
near minima, and the $O(N)$ cost makes it attractive compared to
second-order methods that explicitly manipulate the Hessian.

\paragraph{What might change the picture.}
Two directions could yield non-trivial curvature corrections:
\begin{enumerate}[leftmargin=1.8em]
    \item \textbf{Learnable metrics.}
    When $\gamma$ depends on $\theta$ (Sections~\ref{sec:scalar}--\ref{sec:diag}),
    $\partial_k\gamma_{ij}\neq 0$ adds extra terms to the Christoffel symbols.
    The bracket identity~\eqref{eq:bracket} no longer holds, and the
    Riemannian Hessian may not be proportional to $H$.
    \item \textbf{Log-loss embedding.}
    The variant $f(\theta)=\log\loss(\theta)$ changes the gradient
    from $l_i$ to $l_i/\loss$ and modifies the Hessian structure,
    potentially yielding different curvature properties.
\end{enumerate}
